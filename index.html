Culinary Canvas Tools

Lab Tools runs inside Canvas, using your Canvas login. Student data goes only between your browser and Canvas — it never passes through this website, which only serves the app's code. Install a launcher below, then open it from Canvas.

Laptop — bookmarklet

  1. Show your bookmarks bar, then drag this button onto it: Lab Tools
  2. Open any Canvas page while logged in, then click the bookmark. Lab Tools opens in a new tab.

If nothing opens, allow pop-ups for Canvas. Reloading the Lab Tools tab blanks it — just click the bookmark again; nothing is lost.

iPad — one-tap launch (Userscripts)

  1. Install Userscripts (free, open source) from the App Store, and turn it on in Settings › Safari › Extensions, allowed on .
  2. In Userscripts, add a new script and paste this in:
  3. In Safari, open and add it to your Home Screen or bookmarks. That opens Lab Tools in one tap.

      
Use Safari, not the Canvas app — the Canvas app can't run Lab Tools. If tapping a Canvas link opens the Canvas app, type the address in Safari instead.
